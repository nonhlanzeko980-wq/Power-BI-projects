## Projects

### 1. IT Spend Analysis

**Objective:** Analyse IT expenditure, spending trends, and budget performance to support cost management and financial planning.

**Reports included:**
- **Plan Variance Analysis:** Examines differences between planned and actual spending.
- **Runway IT Spend Analysis:** Visualizes IT spending trends over time.
- **YTD Spend by Cost Elements:** Analyses year-to-date expenditure by cost element.
- **IT Spend Analysis Table:** Presents IT spending information for analysis.

**Business value:** Helps identify spending patterns, monitor budget performance, and support better cost-control decisions.

### 2. Retail Spend Analysis

**Objective:** Analyse retail sales performance, store performance, and sales trends using interactive Power BI dashboards.

**Reports included:**
- **Overview:** Provides a high-level summary of retail performance.
- **District Monthly:** Analyses monthly performance across districts.
- **KPI:** Highlights key performance indicators.
- **New Stores:** Examines new-store performance.
- **Regular vs Markdown Sales:** Compares regular-price and markdown sales.
- **Sales by Category:** Analyses sales across product categories.
- **TY, LY & Variance:** Compares this year's performance with last year's results and identifies variances.

  ## File Structure & Contents
The underlying structure of the Power BI package includes:
* **Report/Layout**: Defines the visual elements, pages, and formatting of the dashboard.
* **Data Model**: Contains the underlying data schema, relationships, and tables.
* **Diagram Layout**: Stores the layout arrangements for the data model relationships.
* **Metadata & Settings**: Configuration and operational properties for the report.
* **Base Themes**: Custom JSON themes (e.g., `CY26SU05.json`) applied to the report's color palette and styling.

**Business value:** Supports sales performance monitoring, trend identification, and data-driven retail decisions.
